# 配置与密钥管理

建立配置加载、环境覆盖、启动校验和密钥注入方式时读取。普通配置以文件为主，需要外部注入的字段显式声明环境变量映射；组件和文件格式适配目标技术栈。

## 适用条件与产出

适用于存在运行配置的应用、工具或库。仅为实际配置建立所需能力；库允许由宿主传入配置，不强制读取宿主进程环境或本地文件。

产出包括统一加载与校验入口、公共配置与无秘密示例、环境变量映射、必要的本地初始化方式、项目长期配置规范及实际验证结果。已有配置机制时复用，识别语义差异再调整，不叠加第二套加载入口。

## 配置来源与合并

### 分层与优先级

按以下顺序合并，后者优先：

1. 公共默认配置：可提交的普通参数与合理默认值。
2. 环境配置：开发、测试或生产等环境的普通差异。
3. 个人本地覆盖：不提交的开发配置。
4. 已映射环境变量：显式允许注入的字段。

本地环境变量可来自 `.env`，进程注入值优先于 `.env`。先合并这两类环境变量，再通过已声明映射覆盖文件配置；两阶段采用相同的空值语义。

嵌套对象按字段合并，数组整体替换。具体文件名沿用技术栈惯例；YAML 可以作为适合结构化配置的选择，不要求所有语言使用同一解析库。

### 加载前的引导参数与路径

- 环境选择、配置目录及 `.env` 开关和显式文件路径属于加载前的最小引导范围。集中定义其来源、优先级与校验，在读取受其控制的文件前确定；被加载的 `.env` 或普通配置不能反过来改变自身的环境、位置或加载开关。具体进程变量、命令行或宿主参数按工程选择，不套用普通字段的合并规则形成循环。
- 说明默认目录、显式路径和相对路径的解析基准，例如工程根、所属包或入口位置；选择依据应能从项目入口确认。不自动搜索无关文件，也不依赖启动机器上未声明的目录状态；构建产物的路径规则不能隐含依赖仅开发环境存在的源码布局。
- 显式指定的文件缺失、不可读或内容非法时失败并给出安全提示；可选默认文件仅在已声明允许缺失时跳过，存在但非法的文件不能静默忽略。未指定文件与显式指定不存在文件的行为应区分。
- 分别声明开发、测试与生产是否允许个人覆盖及 `.env`，测试入口不隐式继承开发者个人文件。生产包排除个人本地覆盖和秘密文件，支持关闭 `.env` 加载；生产使用进程注入时关闭本地环境文件读取。
- 配置库若额外提供主机名、命令行或其他隐式覆盖来源，核对实际读取与合并顺序，按已声明规则适配，不让额外来源改变引导边界或字段映射。

### 显式映射与值语义

- 普通参数主要在配置文件维护；秘密及需要外部注入的部署参数声明对应环境变量和解析类型。没有映射的变量不自动成为应用配置。
- 未设置的字段沿用低优先级值；显式空字符串作为实际输入，由字段规则判断是否允许。必填密钥为空时校验失败，不回退到文件中的旧密钥。
- `false` 和 `0` 保留为实际输入，不能因为假值判断而回退。环境变量的文本按明确类型转换，非法布尔值、数字或结构化值报错，不静默取默认值。
- 可选字段如允许通过空值关闭功能，在字段定义中写明；其他特殊值由字段规则明确处理，避免加载器自行猜测。
- 空值和合并语义以本模块要求为准。若组件默认忽略空字符串等行为不一致，应选择合适机制或做最小适配，并验证最终结果。

## 统一加载与启动校验

- 普通配置从统一入口读取，合并与类型转换完成后校验必填项、类型、取值范围及字段间约束，得到可供业务使用的配置对象。
- 应用在连接外部服务、启动监听或后台任务前完成本地配置校验。辅助脚本复用相同加载规则，只校验自身需要的字段；库在初始化或宿主显式验证时执行。
- 业务代码使用已校验的配置，不分散读取文件和进程变量。引导参数遵循上述最小读取范围及路径规则，应用和辅助入口保持一致语义。
- 错误提示包含字段名和失败原因，能可靠识别时补充来源文件或变量名。不输出秘密值、完整配置或可能携带原始输入的解析器异常；无法安全提取细节时使用不含配置值的提示。
- 配置默认启动时加载，修改后重启生效。热更新及自动密钥轮换不作为基础实现；有实际需求时另行确定一致性、失败处理及生效规则。

## 密钥与本地文件

- 第三方凭据由使用者或部署环境提供；公共配置、示例、日志和错误信息不包含真实秘密。字段说明应指出哪些值必填及如何提供。
- 应用自身需要的随机密钥可通过独立初始化命令生成，使用对应安全库，避免固定默认值。按实际用途生成，不为没有该需求的工程增加密钥体系。
- 工程协议明确要求独立的密钥用途应分别生成，并纳入启动时的字段关联校验，拒绝明显复用；比对解析后的有效密钥材料，不能以不同编码文本视为独立。哪些用途必须分离由工程协议决定，不要求所有秘密互不相同；相等检查不能代替安全生成或证明来源独立，提示只指出违反约束的用途或字段。
- 本地秘密文件采用平台支持的适当访问限制，并排除在版本管理和部署构建输入之外；部署通过既有秘密注入机制提供。生成器和诊断命令不打印秘密值。
- `.env` 作为配置数据解析，保留其支持的特殊字符，不作为 shell 脚本执行。示例文件可以展示变量名和安全的说明性占位值，未补齐的必填项不能被当作可用配置通过校验。

### 本地初始化的失败与并发

仅在提供初始化生成器时适用：保留已有文件与密钥，区分内容有效、待补齐和本次生成成功，普通启动不重新生成。完整校验后安全发布，并发创建不得覆盖已有或其他进程已提交的内容；失败返回非零且不发布残缺结果。临时秘密文件有访问限制，按所有权清理；清理失败保留原错并报告遗留范围，强制终止限制如实说明。

## 实施指引

1. 盘点现有配置入口、字段及秘密来源，确定层级、显式映射、引导路径和环境政策，复用已有加载器。
2. 接通统一转换与启动校验，提供无秘密示例和必要初始化；应用与辅助脚本复用规则，保持 [启动顺序](service-lifecycle.md#启动与失败处理)。
3. 长期规范记录覆盖、路径、环境和初始化策略，字段类型、默认值、映射及用途关联直接链接定义，避免重复维护。外部秘密注入及日志脱敏由对应模块接入，不默认创建秘密管理平台。

## 验收标准

遵循 [测试政策](testing.md#测试政策)，使用隔离目录、进程及合成秘密；配置校验、真实启动、构建产物与外部认证分别报告。

- 合成配置覆盖四层优先级、进程值与 `.env`、对象合并和数组替换；缺失、空串、`false`、`0` 及非法类型按声明处理，未映射变量不覆盖配置。
- 引导在加载前确定，路径及显式／默认文件缺失行为正确，配置不能改变自身加载规则；开发、测试与生产遵守个人文件政策。
- 必填、范围及用途关联校验在真实启动入口连接资源前失败，输出非零且不泄密；辅助脚本只校验所需字段。独立用途密钥的有效材料复用被拒绝，合法独立值可用。
- 有生成器时验证已有内容、失败及并发创建：配置完整发布，不覆盖用户或其他进程的结果，临时秘密按所有权清理，普通重启不改写密钥。
- 调整路径或构建布局时从实际产物及其他工作目录验证加载、调用和停止，个人配置与秘密不进入版本管理及产物；仅有忽略文件不能证明打包安全。缺少产物或部署条件时说明未验证。
